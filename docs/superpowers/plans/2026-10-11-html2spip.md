# html2spip — plan de réalisation

> **Pour les agents :** sous-skill requis : superpowers:subagent-driven-development (recommandé) ou superpowers:executing-plans, tâche par tâche. Les étapes sont des cases à cocher (`- [ ]`).

**Objectif :** une bibliothèque PHP et un plugin SPIP qui convertissent un fragment HTML en raccourcis SPIP, y compris le HTML produit par SPIP (liens internes, notes, modèles, typographie) : un `sale()` amélioré.

**Architecture :** le HTML est analysé en arbre HTML5 (`src/Arbre/`). Des passes de reconnaissance (`src/Reconnaissance/`) remplacent les structures produites par SPIP par des nœuds privés (`h2s-raccourci`, `h2s-note`) ou réécrivent l'arbre. L'écriture (`src/Ecriture/Ecrivain.php`, reprise du convertisseur de wp2spip) parcourt l'arbre et produit le texte SPIP. Un résolveur (`ResolveurSpip` dans SPIP, `ResolveurTableau` dans les tests) relie les URL aux objets.

**Technologies :** PHP 8.1+, ext-dom, `Dom\HTMLDocument` (PHP 8.4) ou Masterminds HTML5-PHP, PHPUnit 10.5, SPIP 4.4 (dernière 4.4.x) en SQLite, SPIP-Cli.

**Spec :** `docs/superpowers/specs/2026-10-11-html2spip-design.md` (annexe A : typographie ; annexe B : formes HTML relevées sur SPIP 4.4.28).

## Contraintes globales

- PHP `>=8.1`, extension DOM. Analyse par `Dom\HTMLDocument` à partir de PHP 8.4, sinon Masterminds HTML5-PHP (Composer, ou copie dans `lib/masterminds-html5/`).
- Namespace `Html2Spip\`, autoload PSR-4 de `src/`. Pas de `declare(strict_types=1)` dans `src/` (code repris de wp2spip, qui n'est pas typé strictement) ; `declare(strict_types=1)` dans les tests.
- Style de wp2spip : tabulations, `array()`, identifiants et commentaires en français, docblocks.
- Ne jamais écrire de mémoire une forme HTML produite par SPIP : tests unitaires tirés des captures du corpus ou de l'annexe B de la spec.
- Ordre des passes : `code`, `notes`, `modeles`, `liens`, `tableaux`, `typographie`.
- SPIP jetable : dernière SPIP 4.4.x, SQLite, dans `tests/spip-jetable/` (ignoré par git), sans autre plugin que html2spip.
- Messages de commit en français, sans trailer (pas de `Co-Authored-By`, pas de `Claude-Session`).
- Le dépôt wp2spip de référence est `/src/wordpress/wp2spip` (lecture seule : rien n'y est modifié).

```php
<?php
/**
 * Constructeur d'arbre de Masterminds HTML5-PHP complété des règles HTML5 qu'il n'applique pas et dont l'absence
 * changerait le texte converti : section et rangée implicites d'un tableau, paragraphe vide pour un </p> orphelin
 *
 * Chargé par Arbre::bodyMasterminds(), une fois Masterminds disponible.
 */

namespace Html2Spip\Arbre;

use DOMElement;
use Masterminds\HTML5\Parser\DOMTreeBuilder;

class ConstructeurMasterminds extends DOMTreeBuilder
{
	public function startTag($name, $attributes = array(), $selfClosing = false) {
		$nom = strtolower($name);
		$parent = ($this->current instanceof DOMElement) ? $this->current->localName : '';
		// Rangée ou cellule directement dans le tableau : dans un tbody implicite
		if (in_array($nom, array('tr', 'td', 'th')) and $parent === 'table') {
			parent::startTag('tbody');
			$parent = 'tbody';
		}
		// Cellule directement dans une section : dans une rangée implicite
		if (in_array($nom, array('td', 'th')) and in_array($parent, array('tbody', 'thead', 'tfoot'))) {
			parent::startTag('tr');
		}
		return parent::startTag($name, $attributes, $selfClosing);
	}

	public function endTag($name) {
		// </p> sans paragraphe ouvert : un paragraphe vide, qui sépare le texte qui l'entoure
		if (strtolower($name) === 'p' and !$this->isAncestor('p')) {
			parent::startTag('p');
		}
		parent::endTag($name);
	}
}
```

- [ ] **Étape 6 : écrire `src/Arbre/Arbre.php`**

```php
<?php
/**
 * Arbre HTML5 de html2spip
 *
 * Dom\HTMLDocument à partir de PHP 8.4 ; sinon Masterminds HTML5-PHP (PHP 8.1 à 8.3), chargé par Composer ou depuis
 * la copie livrée dans lib/masterminds-html5/. Seule cette classe connaît les classes du parseur : le reste de
 * html2spip manipule les nœuds par elle et par les propriétés et méthodes communes aux deux familles de classes
 * (localName, childNodes, textContent, data, attributes, getAttribute(), setAttribute(), hasAttribute(),
 * replaceWith(), remove(), appendChild(), before(), isConnected, ownerDocument).
 */

namespace Html2Spip\Arbre;

use ReflectionClass;
use RuntimeException;

final class Arbre
{
	/**
	 * Éléments sans balise fermante
	 */
	public const VIDES = array(
		'area', 'base', 'basefont', 'bgsound', 'br', 'col', 'embed', 'frame', 'hr', 'img', 'input', 'keygen', 'link',
		'meta', 'param', 'source', 'track', 'wbr',
	);

	/**
	 * Éléments dont le texte est sérialisé sans échappement
	 */
	public const TEXTE_BRUT = array('style', 'script', 'xmp', 'iframe', 'noembed', 'noframes', 'plaintext', 'noscript');

	private static bool $autoload = false;

	/**
	 * Body du HTML analysé en document HTML5
	 *
	 * @param string $html
	 * @return \Dom\Element|\DOMElement
	 * @throws RuntimeException aucun parseur HTML5 disponible
	 */
	public static function body($html) {
		if (class_exists('Dom\HTMLDocument')) {
			return \Dom\HTMLDocument::createFromString(self::source($html), LIBXML_NOERROR)->body;
		}
		if ($erreur = self::verifier()) {
			throw new RuntimeException($erreur);
		}
		return self::bodyMasterminds($html);
	}

	/**
	 * Body du HTML analysé par Masterminds, quelle que soit la version de PHP (tests des deux parseurs)
	 *
	 * @param string $html
	 * @return \DOMElement
	 */
	public static function bodyMasterminds($html) {
		self::chargerMasterminds();
		$arbre = new ConstructeurMasterminds(false, array('disable_html_ns' => true));
		$scanner = new \Masterminds\HTML5\Parser\Scanner(self::source($html), 'UTF-8');
		(new \Masterminds\HTML5\Parser\Tokenizer($scanner, $arbre, \Masterminds\HTML5\Parser\Tokenizer::CONFORMANT_HTML))->parse();
		return $arbre->document()->getElementsByTagName('body')->item(0);
	}

	/**
	 * @param mixed $noeud
	 * @return bool
	 */
	public static function estTexte($noeud) {
		return ($noeud instanceof \Dom\Text or $noeud instanceof \DOMText);
	}

	/**
	 * @param mixed $noeud
	 * @return bool
	 */
	public static function estElement($noeud) {
		return ($noeud instanceof \Dom\Element or $noeud instanceof \DOMElement);
	}

	/**
	 * HTML d'un nœud, contenu compris
	 *
	 * Dom\HTMLDocument::saveHtml() pour l'arbre natif ; sinon l'algorithme de sérialisation du standard HTML5, qui donne
	 * le même résultat (le sérialiseur de Masterminds écrit autrement les attributs booléens et le SVG).
	 *
	 * @param mixed $noeud
	 * @return string
	 */
	public static function serialiser($noeud) {
		if ($noeud instanceof \Dom\Node) {
			return $noeud->ownerDocument->saveHtml($noeud);
		}
		if (self::estTexte($noeud)) {
			$parent = $noeud->parentNode;
			if (self::estElement($parent) and in_array($parent->localName, self::TEXTE_BRUT)) {
				return $noeud->data;
			}
			return str_replace(array('&', "\u{a0}", '<', '>'), array('&amp;', '&nbsp;', '&lt;', '&gt;'), $noeud->data);
		}
		if (!self::estElement($noeud)) {
			return ($noeud->nodeType === XML_COMMENT_NODE) ? '<!--' . $noeud->data . '-->' : '';
		}
		$html = '<' . $noeud->localName;
		foreach ($noeud->attributes as $attribut) {
			$html .= ' ' . $attribut->nodeName . '="' . str_replace(array('&', "\u{a0}", '"'), array('&amp;', '&nbsp;', '&quot;'), $attribut->value) . '"';
		}
		$html .= '>';
		if (in_array($noeud->localName, self::VIDES)) {
			return $html;
		}
		foreach ($noeud->childNodes as $enfant) {
			$html .= self::serialiser($enfant);
		}
		return $html . '</' . $noeud->localName . '>';
	}

	/**
	 * Message si l'arbre HTML5 ne peut pas être construit
	 *
	 * @param bool $dom_natif Dom\HTMLDocument présent (PHP 8.4)
	 * @param bool $dom extension DOM chargée
	 * @param bool $masterminds Masterminds chargé, ou sa copie présente dans lib/
	 * @return string message, ou '' si un parseur est disponible
	 */
	public static function erreur($dom_natif, $dom, $masterminds) {
		if ($dom_natif) {
			return '';
		}
		if (!$dom) {
			return 'Extension PHP DOM absente (PHP ' . PHP_VERSION . ') : elle est nécessaire à la conversion du HTML.';
		}
		if (!$masterminds) {
			return 'Bibliothèque Masterminds HTML5-PHP introuvable (lib/masterminds-html5/ de html2spip) : elle est nécessaire à la conversion du HTML sous PHP ' . PHP_VERSION . ', avant PHP 8.4.';
		}
		return '';
	}

	/**
	 * @return string message, ou '' si un parseur est disponible
	 */
	public static function verifier() {
		return self::erreur(
			class_exists('Dom\HTMLDocument'),
			class_exists('DOMDocument'),
			class_exists('Masterminds\HTML5') or is_file(self::dossierMasterminds() . '/src/HTML5.php')
		);
	}

	/**
	 * Parseur utilisé, pour le mode verbeux
	 *
	 * @return string
	 */
	public static function parseur() {
		if (class_exists('Dom\HTMLDocument')) {
			return 'Dom\HTMLDocument (PHP ' . PHP_VERSION . ')';
		}
		self::chargerMasterminds();
		$fichier = realpath((new ReflectionClass('Masterminds\HTML5'))->getFileName());
		$copie = realpath(self::dossierMasterminds());
		if ($copie and str_starts_with($fichier, $copie . DIRECTORY_SEPARATOR)) {
			return 'Masterminds HTML5-PHP (PHP ' . PHP_VERSION . '), copie de html2spip, version ' . trim((string) file_get_contents($copie . '/VERSION'));
		}
		return 'Masterminds HTML5-PHP (PHP ' . PHP_VERSION . '), copie déjà chargée : ' . $fichier;
	}

	/**
	 * @param string $html
	 * @return string
	 */
	private static function source($html) {
		return '<!DOCTYPE html><html><body>' . $html . '</body></html>';
	}

	/**
	 * Dossier de la copie de Masterminds livrée avec html2spip
	 *
	 * @return string
	 */
	private static function dossierMasterminds() {
		return dirname(__DIR__, 2) . '/lib/masterminds-html5';
	}

	/**
	 * Rend les classes Masterminds disponibles : une copie déjà chargée (Composer, autre plugin) est utilisée telle
	 * quelle, sinon celle de lib/
	 */
	private static function chargerMasterminds() {
		if (self::$autoload or class_exists('Masterminds\HTML5')) {
			return;
		}
		self::$autoload = true;
		spl_autoload_register(function ($classe) {
			if (str_starts_with($classe, 'Masterminds\\')) {
				$fichier = self::dossierMasterminds() . '/src/' . str_replace('\\', '/', substr($classe, strlen('Masterminds\\'))) . '.php';
				if (is_file($fichier)) {
					require $fichier;
				}
			}
		});
	}
}
```

- [ ] **Étape 2 : écrire `src/Arbre/Noeuds.php`**

```php
<?php
/**
 * Nœuds de l'arbre partagés par les passes de reconnaissance et l'écriture
 *
 * Une passe remplace une structure reconnue par un nœud privé que l'écriture sait lire : h2s-raccourci (texte SPIP
 * déjà écrit), h2s-note (contenu d'une note, à écrire entre [[ et ]]).
 */

namespace Html2Spip\Arbre;

final class Noeuds
{
	/**
	 * Texte SPIP déjà écrit : attributs data-spip (le texte) et data-bloc (1 : sur son propre paragraphe)
	 */
	public const RACCOURCI = 'h2s-raccourci';

	/**
	 * Note : contient les nœuds de la note ; attribut data-numero pour une note numérotée à la main
	 */
	public const NOTE = 'h2s-note';

	/**
	 * Nouvel élément dans le document d'un nœud
	 *
	 * @param \Dom\Node|\DOMNode $voisin
	 * @param string $nom
	 * @return \Dom\Element|\DOMElement
	 */
	public static function creer($voisin, string $nom) {
		return $voisin->ownerDocument->createElement($nom);
	}

	/**
	 * Remplace un nœud par un nœud raccourci
	 *
	 * @param \Dom\Node|\DOMNode $noeud
	 * @param string $spip texte SPIP
	 * @param bool $bloc sur son propre paragraphe
	 */
	public static function remplacer($noeud, string $spip, bool $bloc): void {
		$raccourci = self::creer($noeud, self::RACCOURCI);
		$raccourci->setAttribute('data-spip', $spip);
		$raccourci->setAttribute('data-bloc', $bloc ? '1' : '0');
		$noeud->replaceWith($raccourci);
	}

	/**
	 * @param \Dom\Element|\DOMElement $element
	 * @return string nom en minuscules
	 */
	public static function nom($element): string {
		return strtolower($element->localName);
	}

	/**
	 * @param \Dom\Element|\DOMElement $element
	 * @return string[]
	 */
	public static function classes($element): array {
		return preg_split('/\s+/', trim((string) $element->getAttribute('class')), -1, PREG_SPLIT_NO_EMPTY);
	}

	/**
	 * @param mixed $noeud
	 * @param string $classe
	 * @return bool faux pour un nœud qui n'est pas un élément
	 */
	public static function aClasse($noeud, string $classe): bool {
		return Arbre::estElement($noeud) and in_array($classe, self::classes($noeud), true);
	}

	/**
	 * Éléments descendants, dans l'ordre du document, en liste figée : l'arbre peut être modifié pendant le parcours
	 * (un élément retiré garde sa place dans la liste ; isConnected dit s'il est encore dans le document)
	 *
	 * @param \Dom\Element|\DOMElement $racine
	 * @param string $nom nom d'élément, ou * pour tous
	 * @return array
	 */
	public static function descendants($racine, string $nom = '*'): array {
		return iterator_to_array($racine->getElementsByTagName($nom), false);
	}

	/**
	 * Texte comparable : blancs, espaces insécables et fines compris, réduits à une espace ; bords retirés
	 *
	 * @param string $texte
	 * @return string
	 */
	public static function texteNormalise(string $texte): string {
		return trim(preg_replace('/[\s\x{a0}\x{202f}]+/u', ' ', $texte));
	}

	/**
	 * Texte comparable d'un HTML (titre affiché par SPIP…) : balises retirées, entités décodées, blancs réduits
	 *
	 * @param string $html
	 * @return string
	 */
	public static function texteHtml(string $html): string {
		return self::texteNormalise(html_entity_decode(strip_tags($html), ENT_QUOTES | ENT_HTML5, 'UTF-8'));
	}
}
```

```php
<?php
/**
 * Point d'entrée : un fragment HTML en texte SPIP
 *
 * Analyse en arbre HTML5, passes de reconnaissance dans l'ordre de Options::PASSES, puis écriture.
 */

namespace Html2Spip;

use Html2Spip\Arbre\Arbre;
use Html2Spip\Ecriture\Ecrivain;

final class Convertisseur
{
	/**
	 * Classe de chaque passe de Options::PASSES
	 */
	private const CLASSES = array(
	);

	private array $avertissements = array();

	public function __construct(private Options $options = new Options()) {
	}

	public function convertir(string $html): string {
		$html = str_replace(array("\r\n", "\r"), "\n", $html);
		if (trim($html) === '') {
			$this->avertissements = array();
			return '';
		}
		return $this->convertirBody(Arbre::body($html));
	}

	/**
	 * Body déjà analysé (tests des deux parseurs)
	 *
	 * @param \Dom\Element|\DOMElement $body
	 */
	public function convertirBody($body): string {
		$contexte = new Contexte($this->options);
		foreach (Options::PASSES as $passe) {
			if (isset(self::CLASSES[$passe]) and $this->options->passeActive($passe)) {
				$classe = self::CLASSES[$passe];
				(new $classe())->appliquer($body, $contexte);
			}
		}
		$texte = Ecrivain::convertir_body($body, $this->options->ecriture + array('autop' => false));
		$this->avertissements = $contexte->avertissements();
		return $texte;
	}

	/**
	 * Avertissements de la dernière conversion
	 *
	 * @return string[]
	 */
	public function avertissements(): array {
		return $this->avertissements;
	}
}
```

```php
<?php
/**
 * Forme canonique d'un fragment HTML, pour comparer deux rendus de SPIP
 *
 * Les deux fragments sont analysés par le même analyseur HTML5 : entités décodées en caractères UTF-8, attributs
 * triés, nœuds texte faits seulement de blancs retirés (hors pre, textarea, code). Les blancs à l'intérieur du texte
 * sont comparés tels quels. Un retour à la ligne suit chaque fin de bloc, pour des différences lisibles.
 */

declare(strict_types=1);

namespace Html2Spip\Tests\Outils;

use Html2Spip\Arbre\Arbre;

final class HtmlCanonique
{
	private const TELS_QUELS = array('pre', 'textarea', 'code');

	private const BLOCS = array(
		'p', 'div', 'li', 'ul', 'ol', 'dl', 'dt', 'dd', 'table', 'caption', 'thead', 'tbody', 'tfoot', 'tr', 'blockquote',
		'h1', 'h2', 'h3', 'h4', 'h5', 'h6', 'figure', 'figcaption', 'hr', 'br', 'pre', 'textarea',
	);

	public static function de(string $html): string {
		return self::enfants(Arbre::body($html), false);
	}

	private static function enfants($parent, bool $brut): string {
		$html = '';
		foreach ($parent->childNodes as $noeud) {
			$html .= self::noeud($noeud, $brut);
		}
		return $html;
	}

	private static function noeud($noeud, bool $brut): string {
		if (Arbre::estTexte($noeud)) {
			if (!$brut and trim($noeud->data, " \t\n\r\f") === '') {
				return '';
			}
			return htmlspecialchars($noeud->data, ENT_NOQUOTES | ENT_SUBSTITUTE | ENT_HTML5, 'UTF-8');
		}
		if (!Arbre::estElement($noeud)) {
			return '';
		}
		$nom = strtolower($noeud->localName);
		$attributs = array();
		foreach ($noeud->attributes as $attribut) {
			$attributs[$attribut->nodeName] = $attribut->value;
		}
		ksort($attributs);
		$html = "<$nom";
		foreach ($attributs as $attribut => $valeur) {
			$html .= " $attribut=\"" . htmlspecialchars($valeur, ENT_QUOTES | ENT_SUBSTITUTE | ENT_HTML5, 'UTF-8') . '"';
		}
		$html .= '>';
		$fin = in_array($nom, self::BLOCS, true) ? "\n" : '';
		if (in_array($nom, Arbre::VIDES, true)) {
			return $html . $fin;
		}
		return $html . self::enfants($noeud, $brut or in_array($nom, self::TELS_QUELS, true)) . "</$nom>" . $fin;
	}
}
```

```php
<?php
/**
 * Passe Code : blocs dont SPIP garde le texte brut ou les lignes
 *
 * - <cadre> : textarea.spip_cadre, remplacé par le raccourci (texte brut) ;
 * - <poesie> : blockquote.spip_poesie, une ligne par div, réécrit en pre que l'écriture rend en <poesie> (le texte
 *   des lignes y est converti : gras, liens…).
 * <code> (code.spip_code) et <quote> (blockquote.spip) sont rendus par l'écriture.
 */

namespace Html2Spip\Reconnaissance;

use Html2Spip\Arbre\Arbre;
use Html2Spip\Arbre\Noeuds;
use Html2Spip\Contexte;

final class Code implements Passe
{
	public function appliquer($body, Contexte $contexte): void {
		foreach (Noeuds::descendants($body, 'textarea') as $cadre) {
			if (Noeuds::aClasse($cadre, 'spip_cadre')) {
				Noeuds::remplacer($cadre, "<cadre>\n" . trim($cadre->textContent, "\n") . "\n</cadre>", true);
			}
		}
		foreach (Noeuds::descendants($body, 'blockquote') as $poesie) {
			if (Noeuds::aClasse($poesie, 'spip_poesie')) {
				self::poesie($poesie);
			}
		}
	}

	/**
	 * @param \Dom\Element|\DOMElement $poesie blockquote.spip_poesie
	 */
	private static function poesie($poesie): void {
		$pre = Noeuds::creer($poesie, 'pre');
		foreach (iterator_to_array($poesie->childNodes) as $ligne) {
			if (!Arbre::estElement($ligne) or Noeuds::nom($ligne) !== 'div') {
				continue;
			}
			if ($pre->firstChild) {
				$pre->appendChild($poesie->ownerDocument->createTextNode("\n"));
			}
			foreach (iterator_to_array($ligne->childNodes) as $noeud) {
				$pre->appendChild($noeud);
			}
		}
		$poesie->replaceWith($pre);
	}
}
```

```php
<?php
/**
 * Passe Typographie : retire ce que la typographie de SPIP ajoute et remettra au rendu (annexe A de la spec)
 *
 * - apostrophe typographique ’ : apostrophe droite, que SPIP rend de nouveau en ’ ;
 * - espace insécable à un endroit où SPIP en ajoute une : espace normale ;
 * - toute autre espace insécable : ~, nœud raccourci (l'écriture échappe un ~ du texte).
 * Comme corriger_typo(), le texte du code et les attributs ne sont pas traités.
 */

namespace Html2Spip\Reconnaissance;

use Html2Spip\Arbre\Arbre;
use Html2Spip\Arbre\Noeuds;
use Html2Spip\Contexte;

final class Typographie implements Passe
{
	/**
	 * Éléments dont le texte n'est pas traité
	 */
	private const PROTEGES = array('code', 'textarea', 'script', 'style', Noeuds::RACCOURCI);

	private const INSECABLE = "\u{a0}";

	public function appliquer($body, Contexte $contexte): void {
		$fr = self::tableFr($contexte->options->langue);
		foreach (self::textes($body) as $texte) {
			self::traiter($texte, $fr);
		}
	}

	/**
	 * Table de typographie de SPIP pour une langue, comme lang_typo() (ecrire/inc/lang.php)
	 *
	 * @return bool true : table fr ; false : table en
	 */
	public static function tableFr(string $langue): bool {
		return in_array($langue, array('fr', 'eo', 'cpf'), true) or str_starts_with($langue, 'fr_');
	}

	/**
	 * Espace insécable ajoutée par la typographie de SPIP (annexe A, règles fr 3 à 6, en 2)
	 *
	 * @param string $avant texte qui précède l'insécable
	 * @param string $apres texte qui la suit
	 * @param bool $fr table fr
	 */
	public static function ajoutee(string $avant, string $apres, bool $fr): bool {
		if (preg_match('/^--?,/u', $apres)) {
			return true;
		}
		if (!$fr) {
			return false;
		}
		return preg_match('/^(?:[;!?»]|:(?!:)(?:\W|$)|%(?:\W|$))/u', $apres)
			or preg_match('/(?:«|M(?:M?\.|mes?|r\.?)|[MnN]°)$/u', $avant);
	}

	/**
	 * Nœuds texte hors des éléments protégés
	 *
	 * @param \Dom\Node|\DOMNode $racine
	 * @return array
	 */
	private static function textes($racine): array {
		$textes = array();
		foreach ($racine->childNodes as $noeud) {
			if (Arbre::estTexte($noeud)) {
				$textes[] = $noeud;
			}
			elseif (Arbre::estElement($noeud) and !in_array(Noeuds::nom($noeud), self::PROTEGES, true)) {
				array_push($textes, ...self::textes($noeud));
			}
		}
		return $textes;
	}

	/**
	 * @param \Dom\Text|\DOMText $noeud
	 * @param bool $fr
	 */
	private static function traiter($noeud, bool $fr): void {
		$morceaux = explode(self::INSECABLE, str_replace('’', "'", $noeud->data));
		// Texte découpé aux insécables voulues, les autres devenues des espaces
		$segments = array();
		$courant = array_shift($morceaux);
		foreach ($morceaux as $morceau) {
			if (self::ajoutee($courant, $morceau, $fr)) {
				$courant .= ' ' . $morceau;
			}
			else {
				$segments[] = $courant;
				$courant = $morceau;
			}
		}
		$segments[] = $courant;
		$noeud->data = array_shift($segments);
		$precedent = $noeud;
		foreach ($segments as $segment) {
			$tilde = Noeuds::creer($noeud, Noeuds::RACCOURCI);
			$tilde->setAttribute('data-spip', '~');
			$tilde->setAttribute('data-bloc', '0');
			$suite = $noeud->ownerDocument->createTextNode($segment);
			$precedent->after($tilde, $suite);
			$precedent = $suite;
		}
	}
}
```

```php
<?php
/**
 * Passe Tableaux : résumé d'un tableau rendu par SPIP (caption small.summary, après un saut de ligne), sorti de la
 * légende vers l'attribut data-h2s-resume du tableau, que l'écriture rend en || légende | résumé ||
 *
 * Le reste du tableau (en-têtes, cellules fusionnées) est rendu par l'écriture ; les attributs id, headers,
 * aria-describedby et les classes de rangées sont ignorés.
 */

namespace Html2Spip\Reconnaissance;

use Html2Spip\Arbre\Arbre;
use Html2Spip\Arbre\Noeuds;
use Html2Spip\Contexte;

final class Tableaux implements Passe
{
	public function appliquer($body, Contexte $contexte): void {
		foreach (Noeuds::descendants($body, 'caption') as $legende) {
			foreach (Noeuds::descendants($legende, 'small') as $resume) {
				if (!Noeuds::aClasse($resume, 'summary')) {
					continue;
				}
				$legende->parentNode->setAttribute('data-h2s-resume', Noeuds::texteNormalise($resume->textContent));
				$resume->remove();
				self::finDeLegende($legende);
			}
		}
	}

	/**
	 * Blancs et saut de ligne qui précédaient le résumé, retirés de la fin de la légende
	 *
	 * @param \Dom\Element|\DOMElement $legende
	 */
	private static function finDeLegende($legende): void {
		while ($dernier = $legende->lastChild) {
			// && et non and : and est moins prioritaire que l'affectation
			$blanc = Arbre::estTexte($dernier) && trim($dernier->data) === '';
			$saut = Arbre::estElement($dernier) && Noeuds::nom($dernier) === 'br';
			if (!$blanc and !$saut) {
				return;
			}
			$dernier->remove();
		}
	}
}
```

```php
<?php
/**
 * Passe Liens : liens rendus par SPIP (annexe B de la spec)
 *
 * - lien interne (spip_in, ou sans classe vers un objet absent) : href réécrit en raccourci d'objet (40, rub1, doc1…),
 *   texte retiré s'il est le titre que SPIP affiche, bulle gardée ;
 * - URL nue (spip_url auto) : texte ; courriel (spip_mail) : [->adresse] si le texte est l'adresse ;
 * - glossaire (spip_glossaire) : [?terme] si le texte est le terme ;
 * - lien externe (spip_out), appel de note (spip_note) et lien quelconque : laissés à l'écriture ([texte->url]) ou à
 *   la passe Notes.
 */

namespace Html2Spip\Reconnaissance;

use Html2Spip\Arbre\Noeuds;
use Html2Spip\Contexte;

final class Liens implements Passe
{
	/**
	 * Préfixe du raccourci de chaque type d'objet
	 */
	public const RACCOURCIS = array(
		'article' => '', 'rubrique' => 'rub', 'breve' => 'br', 'auteur' => 'aut', 'mot' => 'mot', 'site' => 'site',
		'syndic' => 'site', 'document' => 'doc',
	);

	private const TYPES = 'article|rubrique|breve|auteur|mot|site|syndic|document';

	public function appliquer($body, Contexte $contexte): void {
		foreach (Noeuds::descendants($body, 'a') as $lien) {
			if (!$lien->hasAttribute('href') or Noeuds::aClasse($lien, 'spip_note')) {
				continue;
			}
			$url = trim((string) $lien->getAttribute('href'));
			if (Noeuds::aClasse($lien, 'spip_glossaire')) {
				self::glossaire($lien, $url, $contexte);
			}
			elseif (Noeuds::aClasse($lien, 'auto')) {
				$lien->replaceWith($lien->ownerDocument->createTextNode($lien->textContent));
			}
			elseif (str_starts_with($url, 'mailto:')) {
				self::courriel($lien, $url);
			}
			elseif (!Noeuds::aClasse($lien, 'spip_out')) {
				self::interne($lien, $url, $contexte);
			}
		}
	}

	/**
	 * Objet lisible dans une URL de SPIP, sans résolveur : spip.php?article12, article12.html, spip.php?page=article&id_article=12
	 *
	 * @return array{type: string, id: int}|null
	 */
	public static function objetDansUrl(string $url): ?array {
		if (preg_match('#^[a-z][a-z0-9+.-]*:|^//#i', $url)) {
			return null;
		}
		if (preg_match('#(?:^|/)spip\.php\?(' . self::TYPES . ')(\d+)(?:&|$)#', $url, $m)
			or preg_match('#(?:^|/)(' . self::TYPES . ')(\d+)\.html$#', $url, $m)) {
			return array('type' => self::type($m[1]), 'id' => intval($m[2]));
		}
		parse_str((string) parse_url($url, PHP_URL_QUERY), $requete);
		$page = $requete['page'] ?? '';
		if (!preg_match('#^(?:' . self::TYPES . ')$#', $page)) {
			return null;
		}
		$cle = ($page === 'site') ? 'id_syndic' : "id_$page";
		return isset($requete[$cle]) ? array('type' => self::type($page), 'id' => intval($requete[$cle])) : null;
	}

	private static function type(string $type): string {
		return ($type === 'syndic') ? 'site' : $type;
	}

	/**
	 * @param \Dom\Element|\DOMElement $lien
	 */
	private static function interne($lien, string $url, Contexte $contexte): void {
		[$adresse, $ancre] = array_pad(explode('#', $url, 2), 2, '');
		$objet = ($adresse !== '') ? $contexte->options->resolveur->objet($adresse) : null;
		$trouve = ($objet !== null);
		$objet ??= ($adresse !== '') ? self::objetDansUrl($adresse) : null;
		if ($objet === null) {
			if (Noeuds::aClasse($lien, 'spip_in')) {
				$contexte->avertir("Lien interne non résolu : $url");
			}
			return;
		}
		if (!$trouve) {
			$contexte->avertir("Lien vers un objet absent ou non résolu : $url");
		}
		$titre = $trouve ? $contexte->options->resolveur->titreAffiche($objet['type'], $objet['id']) : null;
		// Objet absent : SPIP affiche « type id » (article 999)
		$titre = ($titre !== null) ? Noeuds::texteHtml($titre) : $objet['type'] . ' ' . $objet['id'];
		$lien->setAttribute('href', self::RACCOURCIS[$objet['type']] . $objet['id'] . ($ancre !== '' ? "#$ancre" : ''));
		$bulle = trim((string) $lien->getAttribute('title'));
		if ($bulle !== '') {
			$lien->setAttribute('data-h2s-bulle', $bulle);
		}
		elseif (Noeuds::texteNormalise($lien->textContent) === $titre) {
			while ($lien->firstChild) {
				$lien->firstChild->remove();
			}
		}
	}

	/**
	 * @param \Dom\Element|\DOMElement $lien
	 */
	private static function courriel($lien, string $url): void {
		$adresse = substr($url, strlen('mailto:'));
		if (Noeuds::texteNormalise($lien->textContent) === $adresse) {
			$lien->setAttribute('href', $adresse);
			while ($lien->firstChild) {
				$lien->firstChild->remove();
			}
		}
	}

	/**
	 * @param \Dom\Element|\DOMElement $lien
	 */
	private static function glossaire($lien, string $url, Contexte $contexte): void {
		$terme = str_replace('_', ' ', rawurldecode((string) basename((string) parse_url($url, PHP_URL_PATH))));
		if ($terme !== '' and Noeuds::texteNormalise($lien->textContent) === $terme) {
			Noeuds::remplacer($lien, "[?$terme]", false);
			return;
		}
		$contexte->avertir("Lien de glossaire dont le texte n’est pas le terme : $url");
	}
}
```

```php
/**
 * Résolveur d'un site SPIP : URL décodées par urls_decoder_url(), objets et titres lus en base
 *
 * Utilisable seulement dans SPIP.

namespace Html2Spip\Spip;

use Html2Spip\Resolveur;

final class ResolveurSpip implements Resolveur
{
	public function objet(string $url): ?array {
		include_spip('inc/urls');
		$adresse = self::locale($url);
		if ($adresse === null or $adresse === '') {
			return null;
		}
		// Document : lien vers son fichier
		if (str_starts_with($adresse, 'IMG/')) {
			$id = sql_getfetsel('id_document', 'spip_documents', 'fichier=' . sql_quote(substr($adresse, strlen('IMG/'))));
			return $id ? array('type' => 'document', 'id' => intval($id)) : null;
		}
		[$fond, $contexte] = array_pad((array) urls_decoder_url($adresse), 2, array());
		$type = $fond ? objet_type($fond) : '';
		$cle = $type ? id_table_objet($type) : '';
		if (!$type or empty($contexte[$cle])) {
			// spip.php?page=article&id_article=3 : non décodé par urls_decoder_url()
			parse_str((string) parse_url($adresse, PHP_URL_QUERY), $contexte);
			$type = isset($contexte['page']) ? objet_type($contexte['page']) : '';
			$cle = $type ? id_table_objet($type) : '';
			if (!$type or empty($contexte[$cle])) {
				return null;
			}
		}
		$id = intval($contexte[$cle]);
		return sql_countsel(table_objet_sql($type), "$cle=$id") ? array('type' => $type, 'id' => $id) : null;
	}

	public function titreAffiche(string $type, int $id): ?string {
		include_spip('inc/lien');
		include_spip('inc/texte');
		$titre = traiter_raccourci_titre($id, $type);
		return isset($titre['titre']) ? typo($titre['titre']) : null;
	}

	/**
	 * Adresse relative au site, ou null pour une adresse d'un autre site
	 */
	private static function locale(string $url): ?string {
		$base = url_de_base();
		if (str_starts_with($url, $base)) {
			return substr($url, strlen($base));
		}
		if (preg_match('#^[a-z][a-z0-9+.-]*:|^//#i', $url)) {
			return null;
		}
		return ltrim(preg_replace('#^\./#', '', $url), '/');
	}
}
```

```php
<?php
/**
 * Passe Notes : notes recousues à leur appel, si l'appel et la note sont dans le même fragment
 *
 * Appel : span.spip_note_ref contenant a.spip_note[href=#nbN] ; note : div#nbN (rendue par #NOTES, dans un
 * div.notes ou non), dont le premier paragraphe commence par le renvoi span.spip_note_ref > a[href=#nhN].
 * L'appel devient un nœud h2s-note qui reçoit le contenu de la note, sans le renvoi ; data-numero pour un numéro
 * qui n'est pas le suivant des numéros automatiques (note numérotée à la main). Appel sans note : retiré ; note sans
 * appel : gardée en paragraphes à la fin du texte ; avertissement dans les deux cas.
 */

namespace Html2Spip\Reconnaissance;

use Html2Spip\Arbre\Arbre;
use Html2Spip\Arbre\Noeuds;
use Html2Spip\Contexte;

final class Notes implements Passe
{
	public function appliquer($body, Contexte $contexte): void {
		$notes = array();
		foreach (Noeuds::descendants($body, 'div') as $div) {
			if (preg_match('/^nb(.+)$/', (string) $div->getAttribute('id'), $m) and self::renvoi($div) !== null) {
				$notes[$m[1]] = $div;
			}
		}
		$suivant = 1;
		foreach (Noeuds::descendants($body, 'a') as $appel) {
			if (!$appel->isConnected or !Noeuds::aClasse($appel, 'spip_note') or !preg_match('/^#nb(.+)$/', (string) $appel->getAttribute('href'), $m)) {
				continue;
			}
			$numero = $m[1];
			$conteneur = Noeuds::aClasse($appel->parentNode, 'spip_note_ref') ? $appel->parentNode : $appel;
			if (!isset($notes[$numero])) {
				$contexte->avertir("Appel de note sans note dans le fragment : $numero");
				$conteneur->remove();
				continue;
			}
			$note = Noeuds::creer($appel, Noeuds::NOTE);
			if ($numero === (string) $suivant) {
				$suivant++;
			}
			else {
				$note->setAttribute('data-numero', $numero);
			}
			$div = $notes[$numero];
			unset($notes[$numero]);
			self::renvoi($div)->remove();
			foreach (iterator_to_array($div->childNodes) as $enfant) {
				$note->appendChild($enfant);
			}
			$div->remove();
			$conteneur->replaceWith($note);
		}
		foreach ($notes as $numero => $div) {
			$contexte->avertir("Note sans appel dans le fragment : $numero");
			self::renvoi($div)->remove();
			foreach (iterator_to_array($div->childNodes) as $enfant) {
				$body->appendChild($enfant);
			}
			$div->remove();
		}
		foreach (Noeuds::descendants($body, 'div') as $div) {
			if (Noeuds::aClasse($div, 'notes') and trim($div->textContent) === '') {
				$div->remove();
			}
		}
	}

	/**
	 * Renvoi d'une note vers son appel
	 *
	 * @param \Dom\Element|\DOMElement $div
	 * @return \Dom\Element|\DOMElement|null span.spip_note_ref, ou le lien seul
	 */
	private static function renvoi($div) {
		foreach (Noeuds::descendants($div, 'a') as $lien) {

				return Noeuds::aClasse($lien->parentNode, 'spip_note_ref') ? $lien->parentNode : $lien;
			}
		}
		return null;
	}
}
```

```php
<?php
/**
 * Passe Modèles : HTML des modèles dist doc, img, emb de SPIP 4.4, rendu en <docN|align>
 *
 * La passe reconnaît une forme HTML (annexe B de la spec), pas l'origine du modèle : un modèle de squelette ou de
 * plugin qui produit la même structure est converti de la même façon. Seul l'alignement est retrouvé ; les autres
 * paramètres (alt, lien, largeur…) sont perdus. Tout autre modèle passe à la conversion générique.
 */

namespace Html2Spip\Reconnaissance;

use Html2Spip\Arbre\Noeuds;
use Html2Spip\Contexte;

final class Modeles implements Passe
{
	/**
	 * Alignement que SPIP donne à <docN> sans paramètre (annexe B) : non écrit
	 */
	private const ALIGNEMENT_PAR_DEFAUT = 'center';

	public function appliquer($body, Contexte $contexte): void {
		foreach (Noeuds::descendants($body, 'div') as $div) {
			if (!$div->isConnected) {
				continue;
			}
			$raccourci = self::raccourci(Noeuds::classes($div));
			if ($raccourci !== null) {
				Noeuds::remplacer($div, $raccourci, true);
			}
		}
	}

	/**
	 * @param string[] $classes classes du div
	 * @return string|null <docN|align>, ou null si ce n'est pas le modèle d'un document
	 */
	private static function raccourci(array $classes): ?string {
		if (!in_array('spip_document', $classes, true)) {
			return null;
		}
		$id = null;
		$align = self::ALIGNEMENT_PAR_DEFAUT;
		foreach ($classes as $classe) {
			if (preg_match('/^spip_document_(\d+)$/', $classe, $m)) {
				$id = $m[1];
			} elseif (preg_match('/^spip_documents_(left|right|center)$/', $classe, $m)) {
				$align = $m[1];
			}
		}
		if ($id === null) {
			return null;
		}
		return ($align === self::ALIGNEMENT_PAR_DEFAUT) ? "<doc$id>" : "<doc$id|$align>";
	}
}
```

```php
<?php

use Symfony\Component\Console\Command\Command;
use Symfony\Component\Console\Input\InputInterface;
use Symfony\Component\Console\Input\InputOption;
use Symfony\Component\Console\Output\ConsoleOutputInterface;
use Symfony\Component\Console\Output\OutputInterface;

class Html2spipConvertir extends Command {
	protected function configure(): void {
		$this
			->setName('html2spip:convertir')
			->setDescription('Convertit du HTML, lu sur l’entrée standard, en raccourcis SPIP')
			->setHelp('Le HTML peut venir de SPIP (propre()) : liens internes, notes, modèles doc/img/emb et typographie sont retrouvés. Avec -v, les avertissements (liens non résolus, notes incomplètes) sont écrits sur la sortie d’erreur.')
			->addOption('langue', 'l', InputOption::VALUE_REQUIRED, 'Langue du texte, qui choisit la typographie à inverser (langue du site par défaut)');
	}

	protected function execute(InputInterface $input, OutputInterface $output): int {
		global $spip_racine;
		global $spip_loaded;

		if (!$spip_loaded) {
			$output->writeln('<error>Vous devez lancer la commande depuis un site SPIP.</error>');
			return Command::FAILURE;
		}
		chdir($spip_racine);
		include_spip('inc/html2spip');
		$output->writeln(html2spip((string) stream_get_contents(STDIN), $input->getOption('langue') ?: null), OutputInterface::OUTPUT_RAW);
		if ($output->isVerbose()) {
			$erreur = ($output instanceof ConsoleOutputInterface) ? $output->getErrorOutput() : $output;
			foreach (html2spip_avertissements() as $avertissement) {
				$erreur->writeln($avertissement, OutputInterface::OUTPUT_RAW);
			}
		}
		return Command::SUCCESS;
	}
}
```

```markdown
# html2spip

Conversion d'un fragment HTML en raccourcis SPIP : un `sale()` amélioré. Le HTML est analysé en arbre HTML5, et non
par expressions régulières. Le HTML produit par SPIP 4.4 est reconnu : liens internes (`[->123]`), notes, ancres,
tableaux, `<cadre>`, `<code>`, `<poesie>`, modèles `doc`, `img`, `emb`, typographie française et anglaise.

## Bibliothèque

PHP 8.1 ou plus, extension DOM. `Dom\HTMLDocument` est utilisé à partir de PHP 8.4, Masterminds HTML5-PHP avant.

    composer require technova69/html2spip

    use Html2Spip\Convertisseur;
    use Html2Spip\Options;
    use Html2Spip\ResolveurTableau;

    $texte = (new Convertisseur(new Options(langue: 'fr')))->convertir($html);

Hors SPIP, un lien interne n'est retrouvé que si son URL contient le type et l'identifiant de l'objet
(`spip.php?article12`). `ResolveurTableau` permet de fournir les URL et les titres.

## Plugin SPIP

Le dépôt est aussi un plugin SPIP 4.4. Il fournit `html2spip($html, $langue)` (`include_spip('inc/html2spip')`), qui
résout les liens par les URL et la base du site, et la commande `spip html2spip:convertir` (HTML sur l'entrée
standard ; `-v` pour les avertissements).

## Limites

- `<multi>` : seul le texte de la langue rendue est gardé.
- Notes : recousues seulement si l'appel et la note sont dans le fragment.
- `<html>…</html>` : converti comme du HTML quelconque.
- Modèles : seule la forme HTML des modèles `doc`, `img`, `emb` est reconnue, avec leur alignement. Les autres
  modèles sont convertis comme du HTML quelconque ; un modèle qui imite cette forme devient `<docN>`.
- Une forme canonique est choisie parmi des variantes équivalentes (`[->123]`, `a :`, `—`).

## Tests

    composer test                  # unitaires, sans SPIP
    composer test-integration      # installe un SPIP 4.4 jetable (SQLite), puis tout le corpus
```
